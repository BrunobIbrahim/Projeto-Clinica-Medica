# 🏥 Clínica Médica

Projeto desenvolvido durante meus estudos de **Desenvolvimento Web**, com o objetivo de praticar a criação de um site para uma clínica médica, aplicando conceitos de **HTML5 e CSS3**, incluindo técnicas de responsividade.

O projeto simula o site de uma clínica médica, apresentando informações sobre os serviços oferecidos, especialidades médicas e atendimento, com uma interface organizada, intuitiva e adaptável a diferentes tamanhos de tela.

---

## 📌 Sobre o projeto

A **Clínica Médica** foi desenvolvida como um projeto de aprendizado para colocar em prática os conhecimentos adquiridos durante meus estudos de desenvolvimento web.

A proposta foi criar uma página visualmente agradável e funcional para uma clínica médica, trabalhando a estruturação do conteúdo, a organização dos elementos, a estilização da interface e a adaptação do layout para diferentes dispositivos.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

---

## 💻 Funcionalidades

- Página inicial com apresentação da clínica
- Seção de informações sobre os serviços oferecidos
- Apresentação das especialidades médicas
- Organização de informações em seções e cards
- Navegação entre as seções da página
- Layout responsivo para diferentes tamanhos de tela

---

## 📚 O que aprendi

Durante o desenvolvimento deste projeto, pude praticar:

- Estruturação de páginas utilizando **HTML semântico**
- Organização de conteúdo utilizando diferentes elementos HTML
- Estilização de páginas utilizando **CSS**
- Utilização de **Flexbox** para organizar elementos
- Criação e estilização de listas e cards
- Trabalho com imagens e elementos visuais
- Utilização de variáveis CSS com `:root`
- Criação de **media queries** para responsividade
- Adaptação do layout para diferentes resoluções de tela
- Organização de arquivos e pastas de um projeto web
